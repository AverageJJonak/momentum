=== PATTERNS
- MenuArt extension (the print shop grows, nothing parallel)
  GEN: Extend MenuArt.Make(string key, int w, int h, Func<int,int,float> alpha, FilterMode filter = Bilinear, TextureWrapMode wrapU = Repeat, TextureWrapMode wrapV = Repeat) and set t.wrapModeU / t.wrapModeV. Make Hash public as MenuArt.Hash01(int x, int y, int seed). Add a flipY parameter to Tile (texcoord Rect(u0, 1, uw, -1)). Add MenuArt.Warm() that touches every texture below once; MenuStyle.EnsureStyles calls it so nothing is generated mid-frame later. Remember Unity texture row 0 is the BOTTOM row: 'y > edge' in Torn means solid at the drawn top, torn at the drawn bottom.
  USE: Every pattern below. No MenuTex class, no second cache.

- SCAN_SHARP
  GEN: MenuArt.ScanSharp(): Make('scan4sharp', 4, 4, (x,y) => y == 3 ? 1 : 0, FilterMode.Point, Repeat, Repeat). Drawn by MenuStyle.Scan(rect, alpha, phasePx, sharp:true): tilePx = max(3, round(4 * UIScale.Factor)) window pixels per tile (5 at 1080p, 6 at 1440p) so the line lands on whole window pixels; canvas px per texel = tilePx / (4 * Factor); MenuArt.Tile(rect, tex, thatScale, new Vector2(0, -phasePx)). Tint GUI.color = (0,0,0,alpha).
  USE: Axis-aligned or SKEWED surfaces only: the pause and report-card overlays (0.10, static, one full-screen Tile) and the HUD slabs (0.10, static). Never under rotation (Point filtering shimmers).

- SCAN_SOFT
  GEN: EXISTING MenuArt.Scanlines(4, 1.4): 4x4 bilinear, one 1.4 px line per 4 px. Drawn by MenuStyle.Scan(rect, alpha, phasePx, sharp:false) = Tile(rect, tex, 1, (0, -phasePx)) under whatever rotation is current.
  USE: Every ROTATED surface: the band slab (0.14, 12 px/s), idle rows and cards (0.12 / 0.10, static), the selected row and card body (0.12 / 0.10, 18 px/s), the rebind banner (0.12, 18 px/s), the boss-intro name strip (0.15, 12 px/s).

- HATCH
  GEN: EXISTING MenuArt.Hatch(16, 3): 16x16 bilinear, 45-degree lines, period 16, 3 px wide, 1 px AA. Drawn by MenuStyle.Hatch(rect, tint, speedPx) = Tile(rect, tex, 1, (Time.unscaledTime * speedPx, 0)).
  USE: Disabled rows (Sick 0.35, static), the D-rank slab (Sick 0.35, static), locked cards (DeepTeal 0.40, 8 px/s), slider fills on the selected row (Ink 0.25, 24 px/s; 72 while hotControl holds it), report bars while growing (Ink 0.25, 48 px/s), the flow frame (Ink 0.30, 24 px/s), health under 35 % (Ink 0.30, 48 px/s).

- HALFTONE
  GEN: EXISTING MenuArt.Halftone(8, 2.6): 8x8 bilinear, one AA dot of radius 2.6 per 8 px cell (~33 % coverage). Tile(rect, tex, 1, (0,0)).
  USE: The print screen over card thumbnails: Ink 0.28 idle, 0.10 on the selected card (the photo comes into focus). Photographs are printed; panels are holograms.

- HALFTONE_RAMP_V
  GEN: NEW MenuArt.HalftoneRampV(int width = 64, int height = 72, int period = 8, float maxRadius = 3.8f): dot grid pitch 8, radius r(row) = maxRadius * smoothstep(1 - row / (height - 1)) so the biggest dots are on row 0 = the drawn BOTTOM; alpha = clamp01(r + 0.5 - dist). Bilinear, wrapU Repeat, wrapV Clamp. Drawn with GUI.DrawTextureWithTexCoords(rect, tex, new Rect(0, 0, rect.width / 64, 1)): tiles horizontally at 1 canvas px per texel, stretches vertically to the rect.
  USE: The band slab's lower 40 % (72 px at scale 1, exactly 1:1) in Bullion 0.9; the CHECKED OUT slab's lower 30 % at half strength (Bullion 0.45).

- TORN
  GEN: EXISTING MenuArt.Torn(256, 24, seed 3, jag 10) with two changes: the edge becomes 1 px anti-aliased (return Mathf.Clamp01(y - edge + 0.5f) instead of the step) and wrapV = Clamp. Solid at the drawn top, torn at the drawn bottom. Drawn by MenuStyle.TornEdge(Rect r, Color c, bool flip, float scale): Tile(r, tex, scale, (0,0), flipY: flip) - scale 0.42 gives a 10 px strip, 107 px per repeat, ~4 px bites; scale 0.25 gives 6 px / 64 px / 2.5 px. For a vertical edge rotate the matrix 90 degrees about the strip's centre first.
  USE: The band's Bond trim (both edges), the 6 px Gold strip under card thumbnails, the rebind banner's two Gold rules, the boss-intro name underline, the flow frame's inner edges (HudGold), the CHECKED OUT slab's top edge. Cut paper instead of ruled lines.

- GRAIN
  GEN: EXISTING MenuArt.Grain(128, 7) but made with FilterMode.Point (pass the new filter argument). Alpha is mostly faint (n * 0.35) with 3 % full specks. Tile(full, tex, 1, offset) with offset = (Hash01(frame, 1, 9) * 128, Hash01(frame, 2, 9) * 128), frame = floor(Time.unscaledTime * 8): the grain re-seats at 8 Hz (projector, not TV). Tint (1,1,1,0.14) - mean effective alpha about 0.025, specks 0.14.
  USE: Pause and report-card overlays only. Never in the HUD, never on the main menu (the street has its own sparks).

- BURST
  GEN: EXISTING MenuArt.Burst(256, rays 24, duty 0.5): 24 wedges, alpha = clamp01(1.15 - r). Clamp wrap (pass it). Drawn centred with UIScale.RotateAround for a slow turn or UIScale.ScaleAround for a flash; MenuStyle.StampBurst(Vector2 pivot, float size, float k, Color c) draws it at scale lerp(1.6, 2.4, k) and alpha c.a * (1 - k).
  USE: Behind the report-card total (Gold 0.12, 520 px, 4 deg/s); the grade-stamp punch (Foil 0.6 to 0 over 0.25 s); behind an S slab (Gold 0.25, 4 deg/s) and an S+ HUD slab (HudGold 0.35, 20 deg/s); the CHECKED OUT impact (Foil 0.6 to 0 over 0.3 s); behind room stamps (StampColor 0.25, 0.3 s). The company's sun.

- RING
  GEN: NEW MenuArt.Ring(int size = 64, float outer = 27, float inner = 24, float gapDeg = 90, float gapAtDeg = -90): alpha = clamp01(outer + 0.5 - d) * clamp01(d - inner + 0.5) * (angular distance from gapAtDeg > gapDeg / 2 ? 1 : 0, with a 2-degree AA ramp). Clamp, Bilinear. One 90-degree gap centred at 12 o'clock so the spin reads.
  USE: The crosshair ring, drawn 22x22 canvas px centred on the crosshair under RotateAround(ringAngle) and ScaleAround(breath).

- BARCODE
  GEN: NEW MenuArt.Barcode(int width = 160, int height = 20, int seed = 1977): an LCG (s = s * 1664525 + 1013904223) lays 40 bars of width 1-4 px with gaps 1-3 px from x = 0, white on clear; alpha 1 inside a bar. Point, Clamp. Drawn stretched to 64x10 (cards), 120x14 (band chip), 90x12 (boss subtitle).
  USE: The asset tag beside a card's code, the band's corner chip, the boss subtitle, the report-card document line. Corporate ornament, never information.

- DASH
  GEN: NEW MenuArt.Dash(int width = 16, int height = 4): alpha 1 for x < 8, else 0. Point, Repeat. MenuStyle.DashFrame(Rect r, Color c, float thick = 2): four Tile calls at scale 1 along the edges (the verticals under a 90-degree RotateAround).
  USE: Ungraded stamp frames, empty secondary key chips, the pause screen's document-frame corner strips.

- STREAK
  GEN: NEW MenuArt.Streak(int width = 512, int height = 64): five gaussian bands (c, w, g) = (64,10,1.0) (140,38,0.5) (260,6,0.9) (330,120,0.35) (450,18,0.7): alpha = clamp01(sum g * exp(-((x - c) / w)^2)) * (1 - |y / 32 - 1|)^1.5, white. Bilinear, wrapU Repeat, wrapV Clamp. Drawn once, stretched to 260 x bandHeight with DrawTexture (ScaleMode.StretchToFill) inside the band's rotated frame.
  USE: The light sweep across the band (Foil, alpha 0.45 * sin(pi * k)), the once-on-select diagonal glint across a card thumbnail (Bond 0.30, 0.45 s).

- LOGO
  GEN: EXISTING GameFont.Logo (128x128, the ring with the bar).
  USE: The selection cursor (18 px Bond, spun in), the selected card's seal (22 px Ink, punched in), the gilt ring behind an S grade on a gold card (1.35x, Ink 0.3), the brand mark bottom-left (28 px Gold 0.85, never glitches), the report-card footer prefix (14 px Gold).
